# 《赋法战争》简体中文汉化

本项目维护《赋法战争》（Enchanted Arms）提取文本的简体中文翻译与润色。唯一工作文本是根目录的 `all_text.json`。以每条记录的 `jp` 为准，并将译文写回同一条记录的 `zh`。`en` 可辅助理解。记录顺序、日文原文、其他字段及游戏标记保持原样。

| 类别 | 文件组 | 记录数 |
| --- | ---: | ---: |
| `MSG` | 45 | 21,522 |
| `OTHER` | 28 | 6,696 |
| `FMG` | 4 | 1,972 |
| `EXTRA` | 3 | 252 |
| 合计 | 80 | 30,442 |

初始数据中的 30,442 个 `zh` 均为空。记录使用 `(category, file, offset)` 组合定位，文件内存在重复的 `id`。

- [PLAN.md](PLAN.md) 记录阶段、批次和验收条件。
- [AGENTS.md](AGENTS.md) 规定译写范围、术语与结构保护要求。
- [MEMORY.md](MEMORY.md) 保存源文件基线和已确认的项目决策。

后续翻译按批次开展。每项验收通过后立即勾选计划，将成果与计划一并提交并推送到 `origin/main`。游戏版本、回封流程及运行时验证待单独确认。项目结构参考 [灰色系列汉化工程](https://github.com/OthinusG/grisaia_zh_localization) 的分批计划和结构验收流程。
